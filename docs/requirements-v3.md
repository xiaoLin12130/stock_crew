## 一、GitHub 调研结论（2026-08-04，克隆 pytdx/easyquotation 源码核对）

| 方案 | 数据源方式 | 对我们可借鉴的点 |
|---|---|---|
| akshare（已用） | 聚合东财/同花顺/新浪/腾讯/通达信 | 现状主源 |
| efinance | 东财接口全封装（纯 HTTP） | 东财备用实现（push2 502 时可对照其请求参数） |
| adata | 东财为主 + 新浪/同花顺 | 同上 |
| **easyquotation** | **新浪/腾讯批量实时行情（hq.sinajs.cn，全市场 200ms）** | **盘中「昨日涨停今日表现」明细的最佳计算源：昨日涨停池 + 批量实时报价** |
| **pytdx / mootdx** | **通达信行情服务器 TCP 直连**（盘中 tick/分钟/盘口/板块/涨跌家数，无需 Cookie） | 解决 F:\tdx 本地陈旧；后续可选模块（需验证代理下连通性） |

| Tushare（已用） | 收盘后日线 | 盘中无当日数据 → 需要盘中替代源 |

## 四、口径（沿用 §六）
- 昨日涨停判定：主板 10%/创业科创 20%（东财池已按此返回）；
- 连板率 = 今日再涨停数 ÷ 昨日涨停数；核按钮率 = 今日跌停数 ÷ 昨日涨停数；
- 红盘率 = 今日上涨数 ÷ 昨日涨停数；平均收益 = 涨跌幅均值（小数）；
- 涨跌家数：全 A（过滤 ST/北证，口径与 Tushare 一致）。
